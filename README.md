# Entropic Session — Activation Steering

Apresentação interativa, versão **2.1**, publicada em:

https://costaleirbag.github.io/ceg-entropic-session/

- [Apresentação interativa](https://costaleirbag.github.io/ceg-entropic-session/)
- [PDF completo — 66 slides](https://costaleirbag.github.io/ceg-entropic-session/pdf/apresentacao.pdf)
- [PDF do percurso principal — 41 slides](https://costaleirbag.github.io/ceg-entropic-session/pdf/apresentacao-essencial.pdf)

A apresentação abre no percurso principal de 41 slides. Os 25 apoios adicionais
ficam disponíveis pelo índice e pelos links de aprofundamento. Setas avançam e
voltam; I abre o índice; B retorna de um apoio; R alterna a leitura contínua.

A versão 2.1 incorpora as dúvidas do estudo: tarefa e avaliação concretas,
construção das direções, escolha da intensidade, repetições e medidas de erros.
Os quatro contrastes de Q2 têm exemplos de código e instruções explícitas.
Os dados e as conclusões científicas são preservados.

Esta publicação contém somente os slides interativos e os dois PDFs dos slides.
As notas do apresentador, o guia, os CSVs e os arquivos de pesquisa não fazem
parte deste repositório.

Publicação estática pelo GitHub Pages: branch `main`, pasta `/ (root)`, sem processamento Jekyll.
