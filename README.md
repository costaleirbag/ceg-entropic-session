# Entropic Session — Activation Steering

Apresentação interativa, versão **2.4**, publicada em:

https://costaleirbag.github.io/ceg-entropic-session/

- [Apresentação interativa](https://costaleirbag.github.io/ceg-entropic-session/)
- [PDF completo — 78 slides](https://costaleirbag.github.io/ceg-entropic-session/pdf/apresentacao.pdf)
- [PDF do percurso principal — 49 slides](https://costaleirbag.github.io/ceg-entropic-session/pdf/apresentacao-essencial.pdf)

A apresentação abre no percurso principal de 49 slides. Os 29 apoios adicionais
ficam disponíveis pelo índice e pelos links de aprofundamento. Setas avançam e
voltam; I abre o índice; B retorna de um apoio; R alterna a leitura contínua.

A versão 2.4 abre com uma breve história do steering e seus conceitos,
as influências de Beaglehole e Wurgaft, COLD-Steer e comparações recentes com
prompts. A introdução conduz aos experimentos, com exemplos concretos da tarefa,
construção das direções, intensidade, repetições e medidas de erros.
Os dados e as conclusões científicas são preservados. O plano de duração é
uma estimativa editorial, sem ensaio cronometrado.

C é explicado primeiro como variância do perfil original menos sua covariância
com o perfil sob steering. O gráfico principal de Q2 resume os mesmos pares
em quatro grupos de distância angular, com medianas e os 50% centrais dos valores.
Essas faixas mostram dispersão; as associações continuam calculadas nos pares
originais e a inferência anterior é preservada.

Esta publicação contém somente os slides interativos e os dois PDFs dos slides.
As notas do apresentador, o guia, os CSVs e os arquivos de pesquisa não fazem
parte deste repositório.

Publicação estática pelo GitHub Pages: branch `main`, pasta `/ (root)`, sem processamento Jekyll.
